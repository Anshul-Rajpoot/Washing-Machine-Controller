# Project Information

## Title
Washing Machine Controller using SystemVerilog FSM

## Category
Digital Design / RTL / Verification

## Main Concepts
- Finite State Machine
- Moore FSM
- Sequential and combinational logic
- Clock-cycle based timing
- Control-signal generation
- Cancellation and safety sequencing
- Self-checking verification
- Continuous integration

## HDL
SystemVerilog

## Simulator
Icarus Verilog

## Entry points
- RTL: `src/washing_machine_controller.sv`
- Testbench: `tb/washing_machine_tb.sv`
